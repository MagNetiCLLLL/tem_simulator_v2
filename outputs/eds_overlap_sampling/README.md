# 重叠加权采样与扫描预览修复

2026-09-08。代码、回归测试和有界对照已加入项目；现有运行中的程序需要重启以载入修改。

## EDS 重叠加权采样

默认启用 `Weighted beam / sample overlap (EDS)`，设置位于
**Sample Interactions 3D → Parameters**。默认 256 个候选积分点，可改为
32–4096；实际保留点数取决于几何交集。关闭选项可恢复原始射线估计。

新方法用带权射线的核密度混合估计连续束流，在样品交集处增加积分点，
保留每点的入射方向、能量和独立材料路径。所有路径保留相对于整个到达
束流的绝对权重，交集电流不会被重新归一为全部电流。EDS 发射位置取自
这些材料路径；原始电子轨迹和下游电子数据保持不变。

当前自动应用于小、薄、无材料支撑体的样品，以及满足密度采样和局部磁场
边界条件的宽束。其他情况会明确显示原因并使用原算法。核密度估计有
平滑和有限射线误差；它不是精确恢复的真实束流，也不是相干波计算。

有界对照使用此前保存的宽束原始相空间，配合明确的基准 Si 样品
（直径 10 nm、厚度 5 nm）、剂量和完整装配。缓存没有完整用户状态，
因此这不是对截图全部设置的精确复现。

| 估计方式 | EDS 总期望计数 |
|---|---:|
| 原始射线，0/7635 条命中 | 0 |
| 256 个候选积分点 | 0.0226388471 |
| 1024 个候选积分点 | 0.0229196817 |

两种积分点数相差约 1.23%；这仅验证该积分对照的稳定性，不证明束流密度
模型或探测器角度积分完全收敛。所有原始 terminal 数组的 SHA256 一致。
该剂量下期望计数远小于 1，Poisson 抽样全零概率仍约 97.7%。

## 截图中的黑白图像

截图显示的是几何/有限粒子探测器预览，尚未进行逐像素 CIF 原子波像计算。
High accuracy 提高射线计算质量，但不会自动勾选 STEM 波像模型。

截图 HAADF 的 0.0010667 与 DF 的约 0.16153 均不是零。恒定正值被原来的
自动色阶画成全黑；BF 从约 0.2354 到 0.235467 的单射线计数差被自动
拉伸成了黑白分界。更改像素尺寸改变了扫描/探测器截断边界，不能据此
解释为样品的原子结构。

现在恒定正值显示为中灰并标明准确数值；变化的几何/粒子预览使用固定
0–1 束流比例色阶，避免将计数台阶夸大。实际原始数组未修改。坐标单位
修复为只进行一次 SI 前缀换算，暂停帧和历史帧使用各自保存的上下文。

下列图是使用截图中的数值重建的独立 Qt 界面显示检查，不是新计算的
Si 原子图，也没有操作用户运行中的程序：

- [0.02 nm，32×32，0.64 nm 视野](scan_preview_002nm.png)
- [0.05 nm，32×32，1.6 nm 视野](scan_preview_005nm.png)

要计算真实 CIF 的逐像素 STEM 图像，在 **Scanning Image → Images** 点击
**Enable CIF wave imaging**，然后运行 **High accuracy**。若勾选了
**Pause refresh**，取消勾选才能显示新帧。大离焦仍需足够大的完整波域；
不能只裁剪强度交集来替代 BF/DF 的相位和真空传播。
