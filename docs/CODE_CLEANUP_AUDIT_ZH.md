### 原有测试问题

首次经典范围验收发现 7 项失败。通过在单独测试进程中载入修改前 HEAD 的原始应用模块，全部 7 项均复现，因此并非此次去重引入。修正范围仅限测试：

- 退休样品模式的拒绝测试改为匹配当前错误提示，仍要求抛出错误。
- 两项样品出射缓存路由测试明确插入样品；当前默认是未插入的 vacuum。
- TEM 波计算的内存拒绝测试明确导入测试 CIF，以进入待验证的内存估算分支。这里只检查预执行拒绝，不启动波计算。
