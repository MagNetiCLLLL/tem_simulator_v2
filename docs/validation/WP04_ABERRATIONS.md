# WP-04：A5、场像差拟合与数值验证

承接用户提供的开发规范 v1.0 和 WP-03。本批加入 A5/C56、独立验证射线、固定硬件的 Cc 能量差分，以及局部多变量校正器响应。以下验证不等于整机或实验标定。

## 界面入口

`Model Inspector → Probe / Image aberrations → Coefficients / fit settings…`

勾选某个系数行后输入覆盖值；不勾选时继续使用原有默认/估计策略。可以编辑 A5 幅值与方向、其他现有系数、拟合半角、最大射线步长、Cc 相对能量差分步长。参数保存在项目状态与 operating profile TOML 中。

Manual 使用配置系数；Field-derived 使用工作线程从场射线拟合的高阶系数，保留手工配置供切回使用。C1 是额外聚焦偏移；射线或 LCT 已包含的聚焦不会再作为拟合 C1 加入。Ideal Optics 仍关闭高阶像差。

完成计算后，原来的 Probe/Image Aberrations 表显示 A5、拟合/独立验证 RMS、场支持范围状态。`Model Inspector → Aberration evidence` 展示并可导出最近一次完成的拟合，包含当时的参数、系数、场网格来源和验证结果。修改参数后，旧报告仍明确属于上次计算。

## 统一约定

共享基底在 `optics/aberration_basis.py` 中声明每项名称、几何阶次、波像差幂次、方位谐波、C_nm 对应及方向字段。长度单位 mm，方向单位 degree，实验室右手 X-Y 坐标。

\[
W_{A5}=\frac{A5}{6}\theta^6\cos[6(\phi-\phi_{A5})],\qquad
\chi=2\pi W/\lambda,\qquad H=\exp(-i\chi).
\]

A5 为五阶几何像差、六次波像差、六重像散；旋转 60° 不变，30° 反号。与 [abTEM Aberrations 源码](https://abtem.readthedocs.io/en/latest/_modules/abtem/transfer.html) 的 C56 / phi56 做了独立相位核对照：系数 mm × 10⁷ 转为 Å，方向 degree 转为 rad。这里使用 C10 本身的符号，不能直接等同 abTEM `defocus` 别名或厂家控制旋钮。

支持 C1/A1/B2/A2/C3/S3/A3/C5/A5；Cc 单独按能量处理。**C41、C43、C45、C52、C54 尚未实现。加入 A5 不代表完整四/五阶模型。**

## 场拟合证据

- 采用解析多项式梯度及按拟合半角缩放的最小二乘矩阵。保持原有前 13 个实系数顺序，追加 A5 的 Cartesian x/y 分量。拒绝秩不足、非有限射线和超出声明半角的输入。
- 拟合使用 192 条射线；独立验证使用另外 161 条不同半径、不同方位的射线。报告每坐标分量 RMS、最大矢量误差、矩阵条件数及验证角度范围。没有用训练残差替代验证误差。
- 记录请求的最大步长，以及每个能量实际积分的步长范围和区间数；场网格可能自动收紧步长。另有物理参考区间、网格形状、间距、范围、内容/几何指纹、场来源及励磁缩放策略。
- 参考区间内存在没有场映射的圆透镜时报告 `partial_field_support`。映射全部圆透镜也不保证多极模型、材料、边界或缺失高阶项已通过实验验证。
- 拟合得到的 C1 仅保留为 `transport_focus_removed_mm` 诊断，不重复用于波传播。场拟合不加手工系数或经验 Cs kick，不伪造校正前后对照。
- Cc 使用固定初始射线、名义参考矩阵/平面、几何和励磁；只改变私有传播能量，不改变电子枪高压控制，不自动聚焦。默认相对能量步长为 0.002、0.001、0.0005，通过各能量导数的角度梯度拟合分离 Cc 与高阶色差污染。
- Cc 连续两次细化均满足 `1e-6 mm + 1% × |Cc|` 才标记该能量步长检查 PASS。这个默认数值阈值是局部检查条件，不是通用物理精度认证。

独立验证射线目前主要位于拟合孔径内部，不能据此外推更大孔径。报告的误差是模型与场射线之间的残差，不是校正后的实际束斑大小。

## 收敛与校正器响应接口

`optics.aberration_validation.convergence_study` 接收独立准备的 `(label, state)` 序列。每次只改变一个数值轴，支持比较拟合半角、积分步长或独立场网格。场网格必须重新求解或从原始模型独立采样；不能将旧场插值加密当成 FEM 收敛。

所有系数在稳定的 Cartesian 坐标中逐项比较，调用者必须明确每个系数的 mm 绝对下限。共用验证孔径必须在所有拟合孔径内部。另比较该孔径内的预测位移，并可传入目标信号计算函数及其单位/绝对阈值。最后两次细化都满足 `absolute_floor + relative_target × |reference|` 才通过；大 C5 不会掩盖小 A1 的不稳定。

`local_corrector_response(state, system, controls)` 接收 2–8 个 `CorrectorControl(key, field, step)`：

- 支持现有百分比、方向、quadrupole `strength_m2`、hexapole `strength_m3` 等控制；结果明确每列的原始控制单位，不虚构安培标定。
- 使用分离的光学对象快照，保留装配/几何和共享组件引用关系，不通过状态反序列化触发硬件初始化。
- 在工作点逐个做 ±step、±step/2 中心差分，输出各系数 Cartesian 分量与 Cc 的局部 Jacobian，以及步长减半后的变化。
- 两组多个控制同时变化的独立检查报告真实值、线性预测值和残差，可暴露交叉非线性。列出每个旋钮实际测试的区间。
- 不自动调参，不把局部线性响应当作整个区间内的有效保证。响应研究仍通过 Python 接口调用；本批未加入自动校正 GUI 或硬件电流标定。

响应向量的 C1 保持排除状态，不能将该行的零值解释成旋钮不会改变一阶聚焦；一阶传输应另行检查。

## 本批验收范围

```powershell
.venv/Scripts/python.exe scripts/validate_aberrations.py --extended --output outputs/aberrations
```

输出 `pytest.log`、`pytest.xml` 和包含代码/测试 SHA256、环境、完整命令、实际数值的 `report.json`。

| 条目 | 验证 |
| --- | --- |
| AT-16 | A5 60° 周期、30° 反号、theta⁶ 缩放；与 abTEM 1.0.10 的混合相位核独立对照 |
| AT-17 | 10/20/32/40 mrad 下混合 C5/A5 与全部已有低阶项恢复；独立验证射线；缺失 C54 导致可见误差 |
| AT-18 | 解析无散磁场的多半角、射线步长、独立网格；逐系数、共用孔径位移及真空探针包围概率比较 |
| AT-19 | 三组能量步长的 Cc 比较；直接检查射线传播调用中的能量变化、硬件与参考区间不变 |
| REQ-AB-06 | 已知交叉非线性控制图的 Jacobian/联合残差；两个实际分布式 hexapole 进入生产传播链 |

AT-18 夹具的系数绝对下限：一阶 1e-7 mm，二阶 1e-5 mm，三阶 0.01 mm，五阶 10 mm；另要求共用 8 mrad 孔径的位移变化满足 1e-11 m + 1% 相对量，真空探针包围概率满足 1e-7 + 1% 相对量。高阶系数的较大长度下限对应小角度高次幂敏感性，不意味着纳米级设备可以容许 10 mm 的几何误差。

积分步长使用 0.012/0.006/0.003 mm，并检查实际积分区间数确实递增；场网格使用 5/9/17 个径向节点，轴向为 2N−1，在同一 0.003 mm 实际步长下比较。其他半角比较也使用相同积分网格，避免把自动步长上限导致的重复计算当作收敛。

夹具使用独立采样的解析磁场，不是独立 FEM 软件或真实物镜数据。探针概率是无样品测试，不能代替 Si STEM/实验图像的收敛。材料/场求解器外部对照和 GPU 相位对照保持 NOT_RUN。新增 CI 任务不代表远端 CI 已运行。
