# WP-05 至 WP-09 实现与验收边界

以用户提供的 `TEM_Simulator_v2_Development_Spec_v1.0.md` 为依据。全部 33 项验收的执行入口为 `scripts/validate_development_spec.py`，测试、数值容差、版本、源码与 CIF/TOML 哈希写入 JSON；跳过、缺少设备、代码在测试中变化和失败都不能记为通过。

## 电气控制与几何作用

`ExcitationCalibration` 定义参考百分比、参考安匝、已知匝数以及来源、日期、不确定度和电流有效范围。百分比是电气控制坐标；已知 N 时 I=NI/N，不代表饱和后 B 与 I 成正比。未知匝数显示电流不可用，禁止从百分比反推一个假定电流。Model Inspector 提供校准及可选的电流修改入口。编辑校准本身不会修改当前镜头强度。

模型切换保持当前线圈百分比和极性。非线性材料仍对完整电流向量联合求解，并验证缓存工作点；不会放大或叠加已经饱和的独立场。

`geometry_effects` 公开尺寸的显示、磁场、真空/光阑和其他计算影响。机械包络、材料区域、场支撑范围与光学参考面各自保留。新增场配方默认要求完整几何；CAD 孔槽或变换不能进入轴对称场时会拒绝计算。用户可明确选用已有轴对称尺寸近似；忽略的部件及策略进入执行记录。旧配方标为 `legacy_authoritative_dimensions`，不追溯改变硬件。严格检查发生在场缓存和整次计算缓存复用之前，联合 B-H 域也参与检查。

## 独立物理基准

有限厚度线圈对照 Biot–Savart 轴上积分；简化的双极靴对照独立编写的磁通有限体积离散。后者与生产 A-phi 三角形 FEM 使用相同材料和边界，采用合成的常数相对磁导率，不是实测仪器材料标定。

Si [110] 的小样品逐项改变网格、视场、切片厚度、频带和热振动组态。探测器上限必须在实际波网格带宽内。abTEM 对照明确使用相同输入势和对齐的对称分步/带宽设置，只能证明传播实现一致，不能独立验证势的生成。另设固定生产链算例，经过控制量、几何磁场、入射射线、晶体、物理光阑和相机，保存通量账本与作用范围。

## GPU 4D-STEM 与通量

GPU 在驻留的探针批次内完成传播、组态强度平均和探测器积分，再同步交付一个衍射批次。写入完成前不继续生产下一批，形成背压。不会为保存立方体在 CPU 重新传播，也不把完整立方体保留在显存。

Host output budget 限制衍射传输批次及写入临时数组，默认 64 MiB；势、图形界面和输入数据内存另计。容不下一帧时明确失败。`auto` 沿用工具栏选择，`prefer_gpu` 允许记录原因后的 CPU 回退，`require_gpu` 在不可用、显存不足或 CUDA 运行错误时停止。数值、业务输入、取消和文件系统异常均不作为 CPU 回退理由。已有 GPU 帧后发生故障保留检查点，不混入 CPU 帧。

衍射以样品前单位探针为参考。带宽裁剪损失不会通过重新归一化恢复。磁场/光阑后的真实剩余权重、剂量、Poisson 抽样和显示缩放各自保留；保存原始概率可重新积分虚拟探测器而无需重新散射。

CPU 使用 complex128，驻留 GPU 使用 complex64。逐衍射像素对照保留 `2e-7` 绝对概率、`2e-4` 相对容差；`1−已收集概率` 是对接近 1 的量相减，绝对舍入误差不能按微小尾部比例缩小。移除退出波重新归一化后，短 FFT 链的未收集余量检查采用每入射电子 `2e-6` 绝对概率预算（约 16 个 float32 epsilon），不改变物理信号或以归一化修补漂移。

格式 2 检查点在数据同步后原子发布完成帧索引、SHA-256 与 RNG 状态。恢复核验帧内容、网格/标定、势、入射 pupil、代码、实际后端和来源。未完成或校验损坏的帧不能算作完成。完成的格式 1 文件仍可读取；缺乏逐帧校验的旧中断文件要求重新开始。多源/多能量 4D-STEM 的角度标定仍明确拒绝；这些模式目前支持探测器图像。

## 执行记录与迁移

TEM、STEM 的 `wave_execution_manifest` 由已运行的节点、模式、切片、像差和探测器信息生成，GUI 和导出共享同一说明。执行完成、范数检查、数值收敛、独立参考和实验标定分别记录；High accuracy 或缓存命中不自动升级验证状态。

操作配置格式 6 保持旧版本读取能力。缺少旧照明定义时明确沿用原射线条件化模式；显式的镜头强度、极性和样品尺寸保留。迁移说明显示在日志，机械几何仍由装配 TOML 决定。GPU 输出策略和内存预算可随配置保存。

CPU 环境完整版本列表位于 `requirements/validation-cpu-lock.txt`。CI 构建 wheel，在隔离环境安装并运行小型 Si 计算及离屏 GUI；GPU 缺失记录为 NOT_RUN。本地 GPU 对照与远程 CI 状态分开记录，远程未执行不能写作通过。
