## M01: combined specimen sampling

Before multiplying by a specimen phase, inspect the represented incident
envelope spectrum, analytical carrier, unwrapped operator increments and
non-affine complex transmission spectrum together. The per-axis guard is
0.8*pi radians per lattice step. Spectral support uses a 1e-12 marginal
probability allowance for the check only; no amplitude, current or mode weight
is removed by it. Affine phases use their known frequency, not the artificial
discontinuity of an FFT-periodic extension.

The review's +0.3 + +0.4 cycle/pixel counterexample now raises
`WaveSamplingError` before multiplication. Independent 200/400 grids at the
same physical period verify the +0.7 frequency and complex amplitude. A weak
sinusoidal phase-modulation counterexample also checks diffraction sidebands;
a small local phase slope alone is not sufficient.

This is a conservative support-sum test for resolved input interpolants, not
proof that an arbitrary sampled potential contains all physical detail. It
can reject nonperiodic/small high-frequency tails conservatively. Automatic
regeneration of the specimen potential and a complete potential-grid
convergence study remain outstanding. The typed rejection deliberately does
not Fourier-upsample an already aliased result or claim that interpolating
the same potential creates new physical information. The existing numerical
band loss, interpolation correction, physical absorption and mode weights
remain separate. Inelastic specimen paths use the same phase operator.

## M02: live lens identities

`live_lens_parameters()` reads the declared fields of the actual installed
lens objects. It replaces the profile serializer as the lens input inventory
for calculation signatures. Profile files still have their original meaning;
assembly-owned values are not written into profiles as independent controls.

The inventory includes both objective poles, their centres/widths, all
Gaussian amplitudes/offsets/sigmas, aberration coefficients and disabled-lens
parameters. Presentation names/colours are excluded. Geometry fingerprints
use the same component inventory, with operating controls excluded there.
Existing model-content, external-file and shared-circuit inventories remain.
The stage schema is now `live-lens-components-v2`, invalidating old numerical
stage identities without deleting their history.

Scope: this closes the reported lens-field omissions. It does not claim that
all components' stage descriptions are already generated from consumed
operators. Broader dependency minimisation and portable restoration are M05.

## M03: shared source-domain policy

Wave generation and Wigner particle emission now use the same deterministic
domain check before sampling. For u~N(mu,S), use

```text
r = |mu| + sqrt(lambda_max(S))*sqrt(-2*ln(epsilon))
epsilon = 1e-8
S = diffraction/incoherent momentum covariance + sigma_x^2*Q*Q^T
```

The two-dimensional Gaussian radial tail gives a conservative probability
bound, not a hard support cutoff. The lowest energy permitted by the declared
spread law is used (the actual energy for a monoenergetic source). This check
does not depend on whether a small finite ray sample happened to miss a tail.

For transverse momentum ratio q<1, the relative error of the quadratic
transverse generator q^2/2 against 1-sqrt(1-q^2) is
`(1-sqrt(1-q^2))/2`. The development admission budget is 1% inside the declared
probability region. Source-domain reports retain the bound and policy; an
error also carries the structured report. This is not an accumulated phase
error estimate or a full-column accuracy assertion.

No source parameters, Gaussian tails, energies or weights are changed.
Classical emission with no selected coherence model is unchanged. Saved
unqualified models remain readable/restorable, but cannot be emitted through
an unsupported active source path. The initial 5 nm / 0.3 eV monoenergetic
coherent default has a conservative generator-error bound about 6.972%, above
this budget. **It is intentionally not silently widened or re-energised.**
Legacy tests expecting that state to execute need model/fixture migration;
their failures must not be represented as completed physical validation.

The new valid-domain statistical fixture explicitly uses a 100 nm tip for
an isolated check. It is not a changed default or a replacement actual
working point. A broader physical gun model and measured/qualified working
points remain M04/M09 work.
