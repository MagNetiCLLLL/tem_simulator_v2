## Scope and current decisions

The user requires correct physical mechanisms and parameter-response trends for
the simulator's own structure. Matching a real instrument's numerical settings
or absolute performance is not required. Declare the observation plane, axes,
operating range and held controls for each trend; a global monotonic response
is not assumed across crossovers, clipping, saturation or mode changes.

The reference records are mixed backups in the confirmed local folder:
`F:\Onedrive\OneDrive - The University of Manchester\Work\TEM_simulator_material\Iliad_files`.
The user confirmed an upgraded instrument with separate cameras before and after
the energy filter. These records inform structure and interactions, not drive
tables for a different simulator geometry. The path and original acquisition
identifiers are provenance, not simulator equipment labels.

- Use scientific or functional equipment names in the UI. Name a sensor CCD or
  CMOS only when the implemented model supports that distinction. Keep original
  acquisitions, URLs and internal compatibility identifiers unchanged.
- Current source work is classical particle emission at the tip. Preserve
  extraction, acceleration, focusing and apertures; never add an independently
  configurable downstream source or normalize away physical current loss.
- Coherent tip-to-column work remains paused. Historical code and results stay
  readable. A few wave-module string changes do not resume wave development.
- Reusable beam states must come from executed upstream transport and be keyed
  by all consumed source, optics, model and numerical inputs.
- Vacuum scattering/attenuation remains opt-in and default-off. Save explicit
  choices; changing participation/settings may invalidate all stages.
- Integrate the energy filter last. A pre-filter detector does not traverse it;
  an unsupported downstream request must not silently bypass it.
- Keep static TOML structure, live operating settings and display state distinct.
  Recalculation must not reset edits; disabling a readout must not remove physical
  interactions or detector absorption.
- Generated arrays and calculation caches stay local. Lightweight reports, code
  and input settings may be versioned; original acquisition records are distinct.
