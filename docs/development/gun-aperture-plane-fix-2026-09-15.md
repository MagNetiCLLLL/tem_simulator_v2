# 电子枪孔径作用平面修复

日期：2026-09-15。范围为经典粒子追迹；按用户要求保留当前电势设置，
电压基准和真实束径的标定留待后续判断。

## 修复内容

默认 FEG 的 C1 开孔位于 Z=445 mm，电子枪与柱镜的交接面位于
Z=450 mm。此前普通 FEG 在交接面应用 C1 开孔，导致部分已经穿过
真实孔径、随后继续展开的电子被错误截获；单色器路径还可能在交接面
重复应用狭缝限制。

现在圆孔或单色器狭缝只在对应组件的实际作用平面判定一次。
交接面负责记录到达电子的位置、动量和时间。保留提取、加速、枪内
聚焦、DPA、实体通孔和装配管壁的原有处理。曲面源在 C1 和交接面
都沿原有保能量积分路径定位穿越事件，未改动电场求解或积分精度。

- C1 的到达记录和透射电流对应实际 C1 平面；出口记录独立保存。
  单色器保留既有狭缝记录标识，读取它不会再次执行狭缝截获。
- 零半径圆孔、零宽度的已插入狭缝完全关闭，修复轴线上有限权重的
  采样电子仍然通过的问题。退出狭缝叶片时仍保留机械通孔限制。
- 校验 DPA、C1 必须位于针尖到交接面的有效传播区间内。
- 更新电子枪和下游计算的缓存版本，旧追迹不能作为新计算的缓存复用。
  历史结果和输入文件的读取格式不变。

实现涉及 `optics/electron_gun/tracing.py`、`aperture.py`、
`field_emission.py` 和 `calculation_cache.py`，位于 `src/temsim` 下。

## 相同输入的完整曲面电子枪复核

采用默认 FEG、193 条发射射线、300 kV、extractor 4 kV、枪透镜
相对 extractor 为 1.2 kV。逐项比较修复前后的完整电子枪输入和
电场报告，两者均相同。所有共同采样的 C1 上游截面（Z<445 mm）
的 D95 差值为 0 mm。

| 指标 | 修复前 | 修复后 |
| --- | ---: | ---: |
| C1 实际执行截获的 Z / mm | 450 | 445 |
| DPA 截获的射线数 | 13 | 13 |
| C1 截获的射线数 | 30 | 28 |
| 到达枪出口的射线数 | 150 | 152 |
| 到达枪出口的电流 / 发射电流 | 77.6042% | 78.6458% |
| 最大出口能量误差 / eV | 3.4343e-9 | 3.4343e-9 |

这里的电流比例按发射权重计算，不是简单用通过条数除以 193。
修复后出口能量仍为 300 keV 加每个电子的初始动能。
出口 D95 为 3.8961 mm；最外采样半径为 2.0037 mm，可以略大于
C1 的 2 mm 开孔半径，因为它已在上游通过 C1，且出口漂移通道
半径为 2.5 mm。该组射线经过生产程序的装配管壁检查后仍有 152 条通过。

本次修复不改变加速管内的上游扩束结果，也没有重新调整枪透镜或
C1/C2/C3 工作点。毫米级束径是否符合真机仍需对应电极几何、
电压基准和发射分布的标定。

标量证据见 [修复验证数据](evidence/gun-aperture-plane-fix-2026-09-15.json)。
本地完整运行记录为 `outputs/setup-validation/accelerator-c1-fixed-193.json`。
此前审查记录及图表继续保留为修复前的结果，见
[加速管束径审查](accelerator-envelope-audit-2026-09-15.md)。
