# 从 FEG tip 到成像的波动计算

当前已有 **tip 发射、实际枪内近轴传播、柱内传播与到达时间扫描线圈、有限样品条件非弹性波和逐模式探测器读出**
的开发路径。完整的 tip → 样品 → TEM/STEM 探测器链尚未完成；生产成像入口继续拒绝不完整的计算。允许增加 tip 参数，不允许增加
独立的已加速源、枪出口源或样品入射源。

## FEG tip 参数清单

所有源输入位于现有 `ColdFieldEmitter`，发射面固定为枪局部 z = 0。
这里描述电子从 tip 出射后的边界条件；尚未从金属能带和隧穿势垒求解发射过程。

| 参数 | 单位 | 定义与约束 |
| --- | --- | --- |
| `emission_current_na` | nA | tip 总发射电流；枪内截断之前。下游电流由逐级损失计算。 |
| `emission_energy_ev` | eV | tip 出射平均动能，必须为正；不等于加速电压。 |
| `minimum_kinetic_energy_ev` | eV | 初始动能下界，低于平均动能。 |
| `energy_spread_fwhm_ev` | eV | 沿用现有能量模型的 RMS 等效 FWHM（2.35482 × 标准差），不是保证非高斯谱线的半高宽。 |
| `young_decay_width_ev` | eV | 现有 Young 低能尾的形状参数。 |
| `boersch_sigma_ev` | eV | 现有 Boersch 展宽模型的形状参数；保留原实现，不宣称已实现多电子自洽空间电荷。 |
| `energy_half_range_ev` | eV | 现有能量分布的有限范围参数；0 沿用原先只有下界的分布。 |
| `virtual_source_fwhm_nm` | nm | 在固定 tip 发射面声明的圆对称高斯强度 FWHM；波动模式必须大于 0。 |
| `coherence` | 可选参数组 | `None` 保留原来的经典发射律；明确选择后使用 tip 的 Gaussian–Schell 互强度。 |
| `coherence.incoherent_angle_rms_mrad` | mrad | 每轴的非相干角度 RMS，非负。总角度还包含衍射展宽和波前曲率贡献。 |
| `coherence.curvature_x_m1` | 1/m | 初始二次相位曲率矩阵 xx。 |
| `coherence.curvature_xy_m1` | 1/m | 初始二次相位曲率矩阵 xy = yx。 |
| `coherence.curvature_y_m1` | 1/m | 初始二次相位曲率矩阵 yy。 |
| `coherence.offset_x_nm`, `offset_y_nm` | nm | tip 发射面的横向发射中心。 |
| `coherence.tilt_x_mrad`, `tilt_y_mrad` | mrad | 平均横向动量 px/p、py/p；近轴时等于方向角。 |

原有 `angular_rms_mrad` 和 `angular_cutoff_mrad` 继续控制经典发射律。选择新的
**tip** 互强度时，这两个经典截断参数不参与该分布；界面明确显示并禁用它们。
Gaussian–Schell 分布有高斯尾部，不能同时当作原来的硬截断位置、硬截断动量分布。
切回经典发射律会恢复原有参数和采样结果。全部真实光阑、单色器和枪体孔径均保留。

亮度、总角度 RMS 和相干长度是同一组发射统计量的相关描述，不能全部独立指定。
当前以电流、空间宽度、非相干角度和曲率为输入；不新增独立下游亮度。
材料、功函数、tip 半径、锥角、真空等原有属性保留，它们尚不足以自动确定发射互强度。
本实现没有假装由这些属性求出了微观发射波函数。

## 数学定义

对每个独立能量样本 E，令 σ = FWHM / √(8 ln 2)，k = p(E)/ℏ，
α 为非相干角度 RMS，Q 为对称曲率矩阵，r₀ 和 t₀ 为发射中心与平均动量方向。

```text
I(r) ∝ exp[-|r-r₀|² / (2σ²)]
φ(r) = k [(r-r₀)ᵀ Q (r-r₀)/2 + t₀·(r-r₀)]
J(r₁,r₂;E) = √[I(r₁)I(r₂)]
              × exp[-(kα)² |r₁-r₂|²/2]
              × exp{i[φ(r₁)-φ(r₂)]}

无曲率时：σθ² = [λ(E)/(4πσ)]² + α²
空间相干长度：ℓc = 1/(kα)；α = 0 对应单个纯横向模。
```

该正半定互强度采用 Hermite–Gaussian 本征模展开。原来的低能默认参数 0.3 eV 和
5 nm FWHM 已经意味着约 **83.9 mrad/轴** 的最低衍射 RMS，不能把 1 mrad 当成总角度。
新增的非相干角度与该最低展宽按方差相加。未自动更改任何保存的工作点或默认发射律。

启用相干参数后，粒子诊断采样同一互强度的正高斯 Wigner 分布；不再拿旧的独立
硬截断射线去猜相位。转换到 Boris 初始方向时保留 px、py 和总动能。非前向动量
不能通过归一化或截断悄悄修复，遇到时明确拒绝。当前仍是近轴源模型，宽角源需要
更一般的前向/反向波表示。

能量继续调用现有正动能 Young/Boersch 采样函数；各能量分量分别传播，按强度混合。
相干模尾部误差、能量采样误差、波网格误差分别记录，不相互替代，不用归一化补回
被截掉的相干模概率或光阑损失。

## 已实现的枪内传播

`physics/tip_gun_wave.py` 从 `generate_tip_emission(gun)` 开始，读取实际安装的场与孔径。
不会接受一个由调用者给出的枪出口波。它执行：

1. 提取电极、静电枪透镜和加速柱的现有电势及横向聚焦。
2. 两组枪偏转线圈和旋转四极枪像散器。
3. 安装时的解析 Wien 电场、磁场和电四极项；使用实际设定，不自动匹配或调参。
4. DPA、C1 圆孔或 C1 双刀狭缝，以及沿枪体采样的吸收孔径。
5. 逐能量传播、连续 metaplectic 相位、Weyl 标量作用量、轴上参考飞行时间和逐级通量。

传播采用**变纵向动量的标量二阶近轴 Hamiltonian**。加速时使用固定的初始参考动量
构造正则变量 (x,y,Px/p_ref,Py/p_ref)，不把不同能量处的机械斜率矩阵当作辛矩阵。
出口只转换相位载波的单位，保留同一复振幅和以 tip 电子为基准的权重。
这是有明确适用范围的新求解器，不等价于已实现任意角度的完整薛定谔/Dirac 方程。

当前枪算子的限制必须保留：高阶非近轴动力学、任意导入 Wien 场、纵向脉冲波包尚未
接入；已有对应粒子功能保留。不能把本算子的近轴结果标为这些功能的波动实现。
狭缝小于波网格可解析宽度时拒绝结果；零面积圆孔必须传输零概率，不能让中心像素漏过。

## 计算缓存

枪检查点的依赖包括完整捕获的枪参数、tip 相干态、实际采样场、实际边界、全部数值参数
和求解器代码身份。先读取实际场，再检查缓存。源电流、枪电压、聚焦、偏转、光阑、
单色器或数值步长变化都会使相关缓存失效。未完成、取消或失败的传播不会发布缓存。
输出包含不可变的复振幅、仿射网格、曲率、倾斜、能量、通量和计算记录。

在界面 **Model Inspector → FEG tip emission…** 中明确启用 tip 相干参数，保存工作
配置后，可用以下开发命令检查参数或导出分阶段计算。命令不会修改输入配置，不会自动
切换发射律。新链目前是静态、标量近轴、零损失相干分量的开发入口，不能当作完整
TEM/STEM 产品验收通过；主界面的正式成像入口仍保留验收限制。

```powershell
.venv\Scripts\python.exe scripts\trace_tip_wave.py --profile my_tip.toml --describe
.venv\Scripts\python.exe scripts\trace_tip_wave.py --profile my_tip.toml --output tmp\tip_wave_run
.venv\Scripts\python.exe scripts\trace_tip_wave.py --profile my_tip.toml --stop detector --observables intensity phase complex --output tmp\tip_detector_run
```

当前默认安装的 **Energy Filter** 尚无接入该链的波动算子。只在所选路径到达其实际
入口或更下游时拒绝请求；默认 HAADF、DF、BF、屏幕和普通相机位于其入口之前，
不应因为下游安装了过滤器而被拦截。上面的命令说明开发接口的调用方式，并不表示当前默认配置已能输出
从 tip 连续计算到探测器的图像。

输出目录必须尚不存在。`receipt.json` 记录物理范围、数值设置和逐能量/光阑结果，
`<stop>_wave.npz` 保存复振幅与相位载波，`request.toml` 保存此次实际输入。
到达探测器时，`detector_readout.npz` 保存所选强度、逐模式相位/有效掩码、复振幅或协方差。
这些导出文件是开发证据，当前没有将任意文件载入为新计算电子源的入口。
请求失败或取消时保存 `failure.json` 和原请求配置，包括报错因果链、最后进度、
数值预算及开始/失败时的代码身份；不会写出成功 `receipt.json` 或把未完成结果当作波检查点。

## 信息传递与可选计算

`simulate_tip_wave(state, TipWaveRequest(...))` 是新开发入口。只能输入仪器状态及计算
选项；电子始终从该状态的实际 FEG tip 开始。每个检查点保留模式身份、能量、tip
参考电流、绝对概率权重、复包络、仿射基、原点、曲率、倾斜、上游记录和依赖身份。
每个模式还直接携带不可变的 `axial_reference`：从 tip 起算的轴上参考飞行时间和
纵向空间作用量 `∫p dz`，由实际枪加速和逐段柱传播累积。冻结声子分支继承它，
探测器吸收、可选读出及导出均保留它，检查点内容身份包含这两个量。未知的历史
参考值使用 `None`，不能当成 0。这不是已求解的纵向脉冲波包，也不是含 `−E dt`
的完整时间作用量；仅给出矩阵端点的路径不能更新这些量，因而不能用于推进该模式。

可选择停止在 `gun_exit`、`specimen_entrance`、`specimen_exit` 或 `detector`。
`--observables` 支持 `intensity phase complex covariance`，不选的结果不生成。
**关闭相位读出不会丢弃传播中的相位**。同一仪器/数值设置下增加读出可复用已执行的
检查点；读出选择不进入传播缓存身份。外部文件、代码、任何捕获的仪器参数或传播
数值设置变化都会使缓存失效。成功的上游阶段可在下游失败后继续复用，失败阶段不缓存。

时间与内存控制包括 `--grid`、`--energy-samples`、`--mode-tail`、`--maximum-modes`、
`--field-step-mm`、`--bore-step-mm`、`--column-step-mm`、`--detector-pixels` 和
`--readout-budget-mb`。这些控制数值精度或结果生成；不能用来关闭实际光阑/透镜作用。
柱内另有 `--maximum-wave-grid`（默认 32768）与 `--wave-budget-mb`（默认 73728 MiB，即 72 GiB）。
检测到六极或 Cs 的非线性相位欠采样时，默认先细化已有复包络，再重试尚未执行的算子。
`--no-wave-refinement` 可关闭自动细化，此时欠采样直接报错；不能在原网格上忽略该作用。
网格上限与内存上限同时生效，默认内存预算不保证能容纳 32768² 的全部工作数组。
内存估计包括本阶段保留的模式、传播矩阵和复波工作数组，不是整个 Python 进程的 RSS 上限。
`--detector` 可以选择已安装并插入的探测器组件 key（例如 `bf`、`df`、`haadf`、
`camera`）；省略时选择沿途第一个开启读出的探测器。之前遇到的探测器照常吸收电子，
即使没有请求它们的读出。相位有效区也受实际传感器形状、偏移和方向约束。
样品区域按完整入射波扩展，保持原定的势采样间距；预算不足时报出需要的资源，
不会自动裁掉束流、缩小样品或把相干模损失归一化补回。

复波重网格只用于坐标变换：比较三次与五次复包络插值，验证完整区域覆盖和积分范数，
再施加明确记录的小幅求积修正。修正不改变模式绝对权重，不能恢复上游光阑损失。
若误差超过阈值，拒绝继续。必须独立收敛源网格、势网格、切片及柱内步长。

柱内自动细化采用正交归一 FFT，将已有复频谱完整嵌入更大频谱；保持物理周期、
原点及解析曲率/倾斜不变。幅度是每个网格单元的概率幅，单元面积缩小时幅度相应缩小，
概率和相位不变。偶数网格保留原有负 Nyquist 频点，不将其拆分或归一化。
这只精确细化已有的周期 Fourier 表示，不能恢复早先已经混叠或被物理光阑吸收的信息。
记录保存每次细化的位置、原因、前后网格、概率和内存估计。

非线性算子检查已知多项式的相位增量与包络频率范围，总预算为 `0.8π`，
频谱尾部概率阈值为 `1e-12`，空间检查覆盖幅度大于峰值 `1e-8` 的相邻点。
不以波零点附近的包裹相位跳变判断混叠。预算不足时，停止在未执行的算子前；
不降低校正器强度、不拟合新的 Gaussian 波、不裁剪束流，也不发布失败阶段的缓存。
自动细化目前用于柱内非线性相位；其他传播和样品势的采样检查仍可能要求另外调整数值参数。

样品势使用已有解析或原子 IAM 构建器，冻结声子构型以独立强度分支保留。每片在
势相位作用之间继续执行柱内 Hamiltonian，避免忽略样品区域的物镜场或重复自由传播。
数值带宽筛选作用于入口及每次半片相位之后的完整波场，并在每片检查已知势相位
算子的 Nyquist 条件；节点或涡旋处的包裹相位跳变不自动代表欠采样。不能将数值带损
解释成真实非弹性散射。选择 `--inelastic-method zero_loss` 时，现有材料 IMFP 决定
零损失相干分量的衰减，损失另外记录。这是有条件的零损失产品，不能代替所有电子的探测器计数。

每片现在按材料竞争事件率，将离开零损失分支的概率划分为首次 plasmon、首次电离、
首次其他非弹性事件和首次有效吸收，保留父模式、能量、参考时间/作用量、特征损失及角度。
只划分**第一次离开零损失分支**，不能当作最终能损谱或后续多次散射的分布。
此零损失分支的事件账本仍标为 `OUTGOING_WAVE_NOT_COMPUTED`，事件间相位为 `UNDEFINED`；
需要出射波时选用下面的条件轨迹方法。
逐冻结声子分支检查：零损失输出 + 柱内吸收 + 首次事件 + 数值带宽损失 = 该分支输入。
数值带损不能混入真实吸收，也不能将尚未传播的非弹性概率算入探测器计数。

## 动态扫描与条件非弹性波

`simulate_tip_scan(state, request, ScanWaveNumerics(...))` 按实际 AC 光学组件的
`scan_pixels_x`、`scan_lines`、`scan_frame_period_s` 产生发射时刻，逐个返回扫描结果。
AC 和 AC Descan 每个实际线圈用该能量模式的 tip 起始参考飞行时间计算到达时刻，
并调用原组件的 `kick_events(time_s=...)`；偏转仍经过实际后续透镜、光阑和样品。
这不是平移样品面 pupil。摆动调用相同到达时间路径；原组件对扫描/摆动互斥的验证继续执行。
该时变模型使用冻结横向切片，不求解线圈场变化导致的纵向能量交换或脉冲波包。

CLI 使用 `--scan --scan-stride 1 --dwell-samples 1 --maximum-scan-positions 4096`。
`stride` 只选择原硬件栅格中的部分位置；`--scan-frame` 指定从下一个完整帧起的帧偏移。
像素标号对应 tip 发射时刻的栅格，实际线圈时刻包含飞行延迟，不冒充已标定的样品落点。
每个位置/驻留结果立即保存完整波与所选读出，`scan_response.npz` 保存驻留加权的每 tip
电子接收概率及覆盖权重。未计算或驻留不完整的位置为 NaN，附实际行列索引，不能解释成零信号。
不选择强度时只保存所选模式读出，汇总强度为 NaN；不同驻留和环境轨迹的相位不平均。

默认 `--inelastic-method trajectories --trajectories 32 --trajectory-seed 0`。
每个源能量/相干模 × 冻结声子构型产生指定数量的条件复波轨迹。每片根据现有材料
Poisson 通道的 Born 概率选择零损失、plasmon、电离、其他非弹性、plural 或吸收。
在有限材料掩码内部施加对应 Kraus 振幅；外部真空只属于无事件结果。条件态归一化
仅表示已采样结果，不把吸收或数值带损补回电子权重。

非弹性事件保留已累积的复相位，按新动量重新表达曲率/倾斜载波；加入原材料通道的
特征散射角及采样方位角，以新能量继续后续样品切片、柱内光学和探测器接收。
模式携带事件位置、能损、动量偏转、随机数、事件时的轴上参考时间/作用量和条件概率。
有效吸收归入独立损失账本；逐轨迹检查输出 + 柱内吸收 + 材料吸收 + 数值带损 = 输入。

这是**现有粗粒度材料分布的局域 Markov 动量转移模型**：使用原有代表性损失/角度及
plural 近似，事件放在切片末端。必须收敛切片厚度、轨迹数及随机种子；没有实现原子
跃迁势、空间非局域介电响应、精细 EELS 边结构或尚缺的高角尾波动通道。
单个条件历史内部可读取相位，独立环境历史间没有可比较的相位。
强度读出报告条件轨迹采样的标量标准误差；单条轨迹无法估计该误差，返回 null。
扫描位置/驻留采用共同随机数，因此这些位置的误差相关，不能按独立噪声合并；此误差也
不包含源截断、能量求积、冻结声子构型数、网格、步长、驻留及物理模型误差。

## 分段执行与 96 GB 机器预算

默认开启分段，`--segment-steps 128` 将原柱积分节点切成多个区间，不重建步长，
不重复施加边界光阑、Cs 或线圈偏转。每段按模式读取、执行、校验并提交到磁盘，再释放
该模式的数组。条件非弹性波按轨迹和样品切片保存，可在取消/失败后重用最后已提交的
切片；随机数由种子、父模式、构型、轨迹和切片索引决定，断点恢复不改变后续抽样。
`--no-segmentation` 切回柱/阶段的内存执行；条件非弹性轨迹仍逐切片保存。

| 控制 | 默认值 | 范围含义 |
| --- | --- | --- |
| `--wave-budget-mb` | 73728 MiB / 72 GiB | 柱波场工作数组估计预算 |
| `--readout-budget-mb` | 73728 MiB / 72 GiB | 当前读出和强度累加的预算 |
| `--gun-budget-mb` | 8192 MiB / 8 GiB | 枪模式集合和工作数组预算 |
| `--ram-cache-gb` | 8 GiB | 非分段阶段 LRU 缓存；分段时清空旧枪/阶段波缓存 |
| `--disk-cache-gb` | 192 GiB | 已执行检查点的磁盘配额，仍受磁盘空闲空间限制 |
| `--cache-directory` | `.temsim-wave-cache` | 私有执行缓存位置，已加入 gitignore |

本机系统可见内存约 95.4 GiB。大数组分配前检查当时可用物理内存，另外预留最多
4 GiB；它不是内存预订，也不是整个进程的 RSS 上限。72 GiB 工作预算与 8 GiB
缓存预算不是预先分配，不能将两个同时活跃的 72 GiB 任务都算作可容纳。

磁盘缓存保存复包络、仿射基、原点、曲率、倾斜、能量、tip 权重、轴上参考和散射历史；
manifest 与逐数组 SHA-256 校验绑定捕获的真实仪器、外部数据内容和求解器代码身份。
查找身份只由执行入口计算；导出的 NPZ 没有导入为电子源的入口。未提交目录不发布，
磁盘配额满时保留已提交结果并报错，不删除上游结果来伪造成功。
同参数和同缓存目录重新执行即可恢复，输出仍需选择新目录。改变已消耗的物理或数值输入
使相关结果失效；不包含动态线圈的上游柱段可跨扫描时刻重用。

当前仍有明确的峰值边界：枪内求解保留该次枪模式集合（受 8 GiB 预算限制），样品势
构建器保留已准备的势构型（沿用原来的构建预算），单个横向 FFT 仍需要整张模式网格。
分段不能把一张网格拆成彼此独立的小图；尚未实现横向分布式 FFT 或完全按需的势构建。
原有 `zero_loss` 路径保留，仍以其完整模式集合检查内存预算。

例如已有物理扫描工作点可运行：

```powershell
.venv\Scripts\python.exe scripts\trace_tip_wave.py --profile path\to\physical_scan.toml --output outputs\scan_run --stop detector --detector bf --scan --scan-stride 4 --dwell-samples 2 --trajectories 16 --segment-steps 128 --observables intensity phase
```

该命令不自动修改实际扫描、发射或光学参数；配置必须具有明确的 tip coherence 和
有效的实际 AC 扫描设置。结果为开发证据，不代表已完成整机成像收敛验收。

## 相位读出含义

探测器保留两类结果：

- 传感器强度：模式强度加权求和、实际传感器形状/方向、像素沉积及已有 PSF。
- 模拟波场：探测器前每个模式的复振幅与相位，使用该模式的真实仿射网格。

相位单位为弧度，范围 `[-π, π]`；零概率或低于所选可见阈值的位置为 `NaN`，并有
独立有效掩码。解析载波始终保留，所以点采样的包裹相位不是已完成的解包裹图像。
非相干模式不能相加成一个复振幅，也没有可定义的“总相位”；不能取平均相位或从
总强度开方来伪造相位。相位规范继承 tip 与连续正则传播，纵向载波独立记账。

这里的相位是模拟器读取波函数，并非普通相机直接测到的相位。真实电子全息需要
同一电子源产生的参考波与物波干涉，再从记录的条纹重建；目前没有凭空增加参考电子源
或宣称完成全息硬件模拟。

当前显式不支持的配置包括：纳秒脉冲器、任意三维场图、枪内额外
非轴对称柱组件、后柱能量过滤器、高角尾波动通道、未经上游执行产生的等效成像透镜状态。原有对应
功能保持可用；新波动入口拒绝这些配置，不能静默关闭它们以生成结果。

按当前开发顺序，先处理能量过滤器之前的柱内传播、扫描与样品分支；能量过滤器最后接入。
该安排不等于关闭实际安装的过滤器，也不把上游阶段验证算作完整探测器图像验收。

## 参考依据

- [Tsujino: field-emission wavefunction and intrinsic transverse energy (2018)](https://doi.org/10.1063/1.5035284)
  ——实际 tip 三维势场会影响发射波，不能将一个平面源边界模型说成已求解微观发射。
- [Khan & Jagannathan: quantum mechanics of magnetic electron lenses](https://arxiv.org/abs/2009.13943)
  ——近轴量子传播、经典极限及高阶项的适用范围。
- [abTEM: partial coherence](https://abtem.readthedocs.io/en/latest/user_guide/tutorials/partial_coherence.html)
  ——独立相干分量按强度平均。
- [abTEM: multislice](https://abtem.readthedocs.io/en/latest/user_guide/walkthrough/multislice.html)
  ——样品势作用与传播交替计算，必须由正确的入射波驱动。
- [abTEM: detectors](https://abtem.readthedocs.io/en/latest/reference/api/_autosummary/abtem.detectors.html)
  ——像素强度读出与模拟复波函数读出是不同结果。
- [SciPy: Fourier resampling](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.resample.html)
  ——周期 Fourier 插值及偶数网格 Nyquist 频点的处理。这里保留复频谱的原有单个频点，
  不直接套用实信号重采样的 Nyquist 拆分规则。
- [JEOL: electron holography](https://www.jeol.com/words/emterms/20121023.070958.php)
  ——物波、真空参考波干涉与相位重建。
- [QuTiP: Monte Carlo trajectories](https://qutip.readthedocs.io/en/stable/guide/dynamics/dynamics-monte.html)
  ——条件态、Born 抽样及轨迹集合的数值方法参考，不是本项目材料模型的验证依据。
- [abTEM: core loss](https://abtem.readthedocs.io/en/main/user_guide/tutorials/core_loss.html)
  ——原子跃迁势与事件后的弹性传播；本项目目前的材料动量转移近似不等同于原子跃迁势模型。
