# 加速过程中横向转折的成因：受控计算与专利比例参考

日期：2026-09-26。用户明确允许参考公开专利中的电极数量、物理配件和间距比例。
本轮新增 12 组、每组 193 个原始发射电子的完整 Z=0–450 mm 经典粒子计算；同时分析
前轮保存的解析场与几何场轨迹。所有对比中的初始位置、动量、时间、ray ID 和权重已逐项
检查完全相同。没有创建下游电子源，没有改变 GUI 或生产默认电场。

## 结论

当前默认配置下，强周期性锯齿主要来自**逐级紧凑解析电势过渡产生过强、过局部的横向场**。
这是场模型层面的表现，减小积分步长没有消除它。绘图的横向放大和稀疏直线连接又放大了
视觉上的尖角。不能把所有横向转折判作错误：几何求场中依然存在边缘聚焦、散焦及弱的
方向过零，但没有复现默认解析场那种强烈的逐级转向。

所有已接受的本轮轨迹在积分试算及保存状态中均保持正的纵向动量，未观察到沿光轴倒退。
这是前向、近轴参数范围内的结果；本诊断遇到非正纵向动量会明确失败，不计算其后折返支路。

## 1. 四种不同的“转折”

| 观察量 | 条件 | 含义 |
| --- | --- | --- |
| 横向位置 | X 过零 | 穿过所画投影轴，不一定改变运动方向 |
| 横向动量/斜率 | px 或 dX/dZ 变号，pz 仍正 | 横向转向，电子仍沿镜筒前进 |
| 横向力 | Fr 变号 | 聚焦/散焦作用改变，不保证已有动量立刻反向 |
| 纵向动量 | pz 过零 | 真正的轴向停转/返回，需要按时间积分与绘制 |

在前轮保存的 80–340 mm 区间，解析场和两种网格几何场的径向力均约有 14 次方向变号，
但相应 X 斜率转向次数和幅度差别很大。因此“力变号次数”不能代替“轨迹是否剧烈摆动”。
阈值为 1e-10 rad 时，平均 X 斜率转向次数为解析场 6.57、几何 16 格 0.244、32 格 0.254。
将可见转向阈值提高到 1e-8 rad（0.01 μrad），后三者分别为 6.33、0、0。
这里只在分析中报告幅度阈值，不删除或平滑实际轨迹。

## 2. 电势的二阶变化怎样产生横向作用

当前解析场在近轴范围采用（r、z 均为 m）：

\[
\Phi(r,z)\simeq\Phi_0(z)-\frac{r^2}{4}\Phi_0''(z),\qquad
E_r=\frac{r}{2}\Phi_0''(z),\qquad F_r=-e E_r.
\]

每个加速级都用一个紧凑平滑阶跃增加电势。阶跃前半段的轴向场增强、后半段减弱，
因此其二阶导数换号，产生方向相反的横向作用。默认半宽只有 4 mm，即一次过渡总长
8 mm，而相邻加速级约相隔 35.56 mm：大段接近零轴向场与狭窄强场峰反复交替。
同电极尺寸的几何求场不具备这种强零场/窄峰分布。

即使没有横向力，纵向加速也能使斜率减小，因为 `dX/dZ=px/pz`。相对论表达式为：

\[
\frac{d^2X}{dZ^2}=-\frac{e\gamma}{mc^2u_z^2}
  \left(E_x-\frac{u_x}{u_z}E_z\right),\qquad \mathbf u=\mathbf p/(mc).
\]

因此需同时查看位置、横向动量、纵向动量和力。仅用图中线段夹角，不能推断电子被反射。

## 3. 保持结构不变，只改变解析过渡宽度

每组都从原始 tip 发射到 450 mm；电极位置、分压、提取、枪透镜、源分布和物理孔径不变。
改变的是每级解析过渡的半宽。下面峰值均在固定 r=1 μm、Z=80–340 mm 处测量：

| 半宽 / mm | 过渡全宽 / mm | 径向场绝对峰值 / V/m | 平均可见 X 转向次数 |
| ---: | ---: | ---: | ---: |
| 2 | 4 | 5340.48 | 5.46 |
| 4（默认） | 8 | 1335.12 | 6.33 |
| 8 | 16 | 333.78 | 13.73 |
| 16 | 32 | 83.445 | 0 |

转向计数使用 0.01 μrad 死区，按实际发射权重统计。峰值横向场精确遵循该函数的
`1/半宽²` 标度；转向次数并不单调，因为全局聚焦、入射横向动量和局部力共同决定是否过零。
这些半宽是因果诊断输入，不是建议把默认半宽直接设为 16 mm。

默认 4 mm 半宽的最大积分步长从 0.25→0.125 mm 后：

- 转向计数保持相同；
- 最大位置差 0.000257 nm；
- 包络差为区间峰值的 7.15e-9（比较范围为整个 0–450 mm 公共保存位置）。

这不支持“积分步长太大是主要成因”的解释。

## 4. 专利比例参考结构

参考 [US8803411B2 Fig. 2，PDF 第 4 页](https://patentimages.storage.googleapis.com/b2/de/20/4b372cd1334732/US8803411.pdf#page=4)
中的常规结构：提取极之外，由静电控制极、四个中间加速电极、接地终端组成六个分压节点，
五段分压。折返电极轮廓用于遮挡绝缘体，也会影响电场；它不要求电子沿折线行进。
[原始说明](https://patents.google.com/patent/US8803411B2/en)

本轮以源位置为 Z=0，将图中源至末端比例缩放至现有加速器机械末端 Z=370 mm；观察位置
仍为 450 mm。手工图示坐标误差约 ±3 PDF 点，没有将其当作标定尺寸。当前提取设置和
控制设置分别产生 4 kV、5.2 kV 对阴极电势；随后五段从控制极向 300 kV 接地终端分压。
生产默认装配未修改。

| 参考部位 | 本轮参考位置 / mm | 备注 |
| --- | ---: | --- |
| 提取极下游唇边 | 2.96–17.76 | 保留提取作用；并非完整提取极包围结构 |
| 控制极主板中心 | 63.64 | 5.2 kV 对阴极 |
| 四个中间电极主板中心 | 122.84、182.04、241.24、300.44 | 等分压间隔；轮廓按图示比例近似 |
| 接地终端 | 355.2–370 | 有限厚度环形金属，不是整个出口面 |

导体用相连的矩形环带近似，静电势共同求解，使用同一插值势的梯度计算电场。配对的
`flat` 对照仅移除四个中间电极的回折部分，保留主板位置、最小孔径、其他电极和全部电压。
原 DPA/C1 孔径仍在执行平面检查，原磁性部件仍保留并检查控制为零；没有因减少电极数
而跳过提取、聚焦、加速或孔径作用。

### 必须保留的参考模型边界

这里仍显式采用整平面阴极。专利图中提取极包围发射体的上游部分与此边界不相容，
所以只建模其下游唇边。绝缘体的介电性质、外部壳体和空间电荷也未求解。
这是**下游电极比例参考**，不是完整专利电子枪的复刻或完整电子枪验证。
相对原结构的比较同时改变了孔径、位置和分压关系；不能单凭该比较把差别全部归因于级数。
只有 `stepped/flat` 配对是在固定其余条件下隔离回折形状的效果。

## 5. 参考结构结果及可靠范围

| 场模型 | r=1 μm、80–340 mm 径向场峰值 / V/m | 平均可见 X 转向次数 |
| --- | ---: | ---: |
| 当前解析场 | 1335.12 | 6.33 |
| 当前几何共同求场，32 格 | 8.74 | 0 |
| 比例参考回折电极，32 格 | 26.95 | 0 |
| 比例参考平板中间电极，16 格 | 27.56 | 0 |

计数阈值同为 0.01 μrad；未据此将更微小的运动从数据中移除。峰值在固定探针位置测量，
不是所有粒子沿途受力的最大值。原始源完全相同，但经过不同上游电场后的状态可以不同。

回折轮廓仍有实际物理作用：同为 16 格时，改为平板后，80–340 mm 内包络差为峰值的
**6.62%**，方向差为该区间峰值的 **7.38%**，最大单粒子方向差 **2.639 μrad**。
出口 RMS 半径由 **0.78443→0.89465 μm**。这些差别明显高于以下数值与边界敏感性。

| 对照 | 80–340 mm 包络差 / 峰值 | 该区间方向差 / 峰值 |
| --- | ---: | ---: |
| 参考网格 16→32 | 0.1101% | 0.1653% |
| 同一物理参考结构，数值出口 450→650 mm | 0.00227% | 0.01097% |

全程 0–450 mm 的网格包络差为 0.1344%，方向差为 0.0659%，两者通过事先声明的 1% 目标。
全程方向归一化受较大源角度影响，故上表另行给出加速器内部的归一化结果。
参考场步长减半后，全程包络差约 1.27e-11；本轮 12 组的能量不变量误差均小于
预设 0.001 eV 上限。各组 193 粒子均完成、通过已检查孔径，未发生隐藏的粒子丢弃。

出口问题仍然存在：保持终端金属在 370 mm，仅把数值出口移到 550/650 mm，450 mm
处平均动能分别为 295015.867/290037.121 eV，而原边界下为 300000.300 eV。
因此模型尚不能成为默认枪场；不过在 80–340 mm 内的转折机制结论对该出口改变很不敏感，
无需把“默认模型尚未完成”误解为本轮成因研究没有结果。

## 6. Ray Diagram 的显示检查

- 原始保存轨迹已经有转折；`RayCurveItem` 的 0.35 像素简化没有改变物理数据。
- 默认公共 Z 绘图间隔约 2 mm，一次 8 mm 过渡只有约四段直线，容易显示成尖角。
- 横向显示放大后的屏幕斜率是物理斜率乘以显示比例，不能把屏幕夹角当作电子真实角度。
- 现有正 Z 图层主要表示各平面首次到达状态。若未来出现真实折返，还需使用按时间排序的
  原始轨迹，并按终止时间截断；仅用最终截获 Z 裁切会丢掉此前到过的更下游区间。
  这是另一个明确的显示限制，不是本轮前向加速器锯齿的原因。
